Settled by the user on 2026-09-30, building M6-B (`#316`), on the recommended option.

# What was ruled

- **The ten named types always**, one row each, as canon §6.6 draws them: HDMI's three weights and
  RG6's three carried families share their type's row.
- **Then one row for each other family** some cable in the set carries.

# How it was priced

The starters were counted before the question was asked: three carry no cables and the fourth uses
four families. A legend of only what is used would print an empty cable key on three of them, and
the one sheet AC-054's photocopy test reads would not contain the ten it checks. Every shipped
family would not fit one ANSI B sheet beside the other five blocks.
