# Practices

Working conventions that earned their place; each is here because it was tested
by something going wrong.

* [A test that asserts an absence names its due date](a-test-that-asserts-an-absence-names-its-due-date.md) - three came due in one task and cost five minutes between them, because each comment said which item would retire it.
* [A deferred action needs a frame](defer-past-the-gesture.md) - addPostFrameCallback queues but does not schedule, and a TabBarView settles the page under a tab switch made mid-click.
* [Assert the artifact, not the mechanism](assert-the-artifact-not-the-mechanism.md) - a test counted corridors, passed, and the sheet painted a fifth of its ink twice.
* [A modelled field is not a reachable one](a-modelled-field-is-not-a-reachable-one.md) - fields with no writer, a callback with no caller, and `NetworkConfig`, whose only writer in the whole tree is the JSON decoder; the last was found by censusing a feature request before pricing it.
* [Check a decomposition for holes](check-a-decomposition-for-holes.md) - a healthy-looking four-task issue had nothing that read a CSV file; ask what produces each task's input, and know a gap from a scope change.
* [A dimension sits in an inequality](a-dimension-sits-in-an-inequality.md) - a 22 mm gang pitch against a 33.34 mm opening is two holes overlapping; the check is free, and the reading was real but was answering a different axis.
* [Census before building](census-before-building.md) - print the field over the whole corpus first; it has caught an empty field, an unmeasured cost and a wrong ordering.
* [Decompose before building](decompose-before-building.md) - the first task of a milestone is its own breakdown, and task descriptions carry the traps.
* [Diagnose before fixing](diagnose-before-fixing.md) - twelve fix commits touched neither cause; what that means and what shape of fix held.
* [The ZIP trap](the-zip-trap.md) - how a file arrives decides whether it is trusted; a property that lives in the channel cannot be gated at the source.
* [Two documents agreeing is not verification](two-documents-agreeing-is-not-verification.md) - three fields named by a ruling AND a design document and present in neither the model nor the codec; a citation is evidence of intent, not of existence.
* [One keymap registry](one-keymap-registry.md) - every binding is a table row, arbitrated across every platform, and why a real collision does not throw.
* [Re-read a task against canon before pricing it](re-read-a-task-against-canon.md) - two of M3-D's four tasks asked questions that rulings dated after them had already answered; the cost that does not announce itself is the estimate.
* [Trade objections are questions, not findings](trade-knowledge-beats-workflow-reasoning.md) - three rulings have overruled an objection grounded in how the work happens in the field; the corpus is silent about the trade, so a workflow claim can be confidently wrong and pass every check here.
* [Measure the control before choosing it](measure-the-control-before-choosing-it.md) - a 55-row dropdown in a 76-point column renders every row as an ellipsised stump; the three sibling columns using the same widget were not evidence, because their labels fit.
